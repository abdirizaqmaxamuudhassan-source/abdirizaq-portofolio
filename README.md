## Run locally
1. Open this folder in VS Code.
2. Open `index.html` in your browser.
3. Or install/use VS Code Live Server and click **Go Live**.

## Important
- Your photo is already included at `assets/profile.jpg`.

- Replace the placeholder GitHub/LinkedIn links with your real profile links.
